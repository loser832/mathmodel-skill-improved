\section{Problem 1: Allocation}
We minimize $3x+2y$ subject to $x+y\geq 10$ and $x,y\geq 0$.
The allocation is $x=0$ and $y=10$. The optimal objective value is 23.
The nonnegative allocation meets the total requirement. Since the unit cost of the second variable is lower, allocating the full amount to that variable minimizes cost.
